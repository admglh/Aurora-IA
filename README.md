# Aurora 9.0 — Base Única

A Aurora 9.0 foi reorganizada como um aplicativo Android mobile-first, com interface própria e arquitetura preparada para inteligência local.

A regra desta base é simples: **não apresentar como pronto aquilo que ainda é um esqueleto**.

O aplicativo possui:

- Aurora Hub visual;
- conversa e histórico;
- exclusão de conversas;
- configurações internas;
- importação de GGUF;
- endpoint compatível com OpenAI;
- memória/persona;
- voz Android com pitch grave ajustável;
- segurança de chaves e armazenamento privado;
- JNI/CMake preparado para o runtime nativo.

Leia `docs/ETAPA_UNICA.md` antes da compilação.


## Atualização visual
A tela inicial usa a animação da Aurora fornecida em vídeo, com fundo substituído por um cenário noturno. A caneta permanece como ícone do aplicativo.
